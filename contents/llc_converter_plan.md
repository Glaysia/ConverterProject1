# LLC 절연형 컨버터 제어 계획

## 1. 목표 정의
- 입력 DC 전압을 누설 인덕턴스를 활용한 센터탭 절연형 LLC 컨버터로 변환해 안정적인 DC 출력 확보
- ZVS 조건을 유지하며 주파수 변조(FM) 제어로 출력 전압을 조절
- 출력 전압이 5 V 기준 이하로 떨어질 때 목표 주파수 대비 순간적으로 주파수를 증가시켜 전압을 회복

## 2. 전력 회로 개요
- 1차: DC 소스 → 풀브리지/하프브리지(선택) → 누설 인덕턴스 포함 센터탭 변압기
- 2차: 다이오드 정류(센터탭 2다이오드) → 출력 커패시터 → 부하
- 주변 요소: LLC 공진 탱크(Lr, Lm, Cr), 스너버/클램프 확인
- 온도/전류 센서 배치 검토(추후 보호 기능 확장 대비)

## 3. 제어 전략
- 스위칭 주파수 기반 열린 루프 기본 곡선 + 출력 전압 피드백을 이용한 보상
- 목표 주파수: 공진점 근처에서 시작, 출력 부하에 따라 LUT 테이블 또는 함수 기반 목표 설정
- 출력 전압 `Vout` 측정 후, 5 V 미만 시 `f_sw`를 사전에 정의한 Δf 만큼 순간적으로 증가 → 전압 회복 후 점진적으로 목표 주파수로 복귀
- ZVS 유지 조건 체크: 최소 주파수 제한, 데드타임 최적화, MOSFET 온도 모니터링
- 단순 PI 또는 비례+데드존 제어로 1차 구현, 이후 보드 실측에 따라 파라미터 튜닝

## 4. STM32CubeMX 설정 계획
- **MCU 선택**: STM32F103 (프로젝트 파일 `ConverterProject2.ioc` 기반)
- **Clock**: 시스템 클록 72 MHz, HSE 사용. PWM 정밀도 확보를 위해 TIM 기반 클록 소스 검증
- **TIM1**: 고해상도 PWM, Complementary 출력, Dead Time 삽입. 주파수 스윕(최소~최대) 범위 계산 후 ARR, PSC 설정
- **TIM3/TIM4**: 보조 타이머 (전류 센싱 트리거, 주파수 램프 구현 등) 고려
- **ADC1**: 출력 전압/전류 측정, 정류 후 RC 필터 고려. 규칙 변환 + DMA 사용해 CPU 부하 감소
- **DMA**: ADC → 메모리 전송, 필요 시 PWM 업데이트 버퍼링
- **GPIO**: 보호 신호 입력(PGOOD, OCP, OTP), 디버그용 LED
- **USART1**: 디버깅/로깅용 시리얼 통신 (출력 전압, 주파수, Fault 상태)
- **NVIC**: 타이머/ADC 인터럽트 우선순위 정의

## 5. 펌웨어 구조
1. `main()` 초기화: HAL_Init → SystemClock_Config → CubeMX 생성 초기화 함수 호출
2. 제어 루프 구성
   - 타이머 업데이트 인터럽트(또는 SysTick)에서 주기적 전압 샘플링 및 제어 실행
   - ADC DMA 완료 콜백에서 최신 전압 계산, LPF 적용
   - ZVS 조건 모니터링(데드타임, 전류 영점 통과) → Fault 발생 시 PWM 차단
3. 상태 머신 설계
   - IDLE → SOFT-START → REGULATION → FAULT
   - 소프트스타트: 주파수 높은 상태에서 시작해 점차 목표 주파수로 이동
4. 주파수 명령 생성
   - 목표 주파수 `f_ref` 계산 (부하 기반 LUT/수식)
   - 보정기 출력 `Δf`로 TIM1 ARR 조정, 주파수 한계 클램핑
5. 통신/로깅
   - USART/printf 재지정으로 실시간 데이터 확인
   - 필요 시 간단한 CLI 명령으로 제어 파라미터 변경

## 6. 보호 및 시험 계획
- **보호 로직**: OVP, UVP, OCP, OTP 감시. Fault 발생 시 PWM Disable 후 경보
- **시험 단계**
  1. 무부하/저부하에서 공진 특성 확인, ZVS 여부 오실로스코프 측정
  2. 주파수-전압 곡선 작성, LUT 보정
  3. 5 V 임계값 테스트: 인위적으로 부하 가변 → 주파수 상승 응답 시간 측정
  4. 장시간 번-인으로 온도/효율 데이터 수집
- **검증 도구**: 디지털 오실로스코프, 전력 분석기, 열화상 카메라(선택)

## 7. 향후 확장 아이디어
- 디지털 제어 고도화 (PI → 모델 기반 제어, 예: PR 컨트롤, MPC)
- CAN/RS485 통신 추가로 외부 제어
- 다중 출력 전압 감시 및 동적 부하 공유
- FW 업데이트/파라미터 조정을 위한 부트로더 적용 검토

## 8. 실행 일정(초안)
- 주차별 목표
  - 1주차: 회로 파라미터 계산, CubeMX 프로젝트 구성, 기본 PWM 구동 확인
  - 2주차: ADC, DMA, 제어 루프 스켈레톤 구현 및 5 V 조건부 주파수 상승 로직 작성
  - 3주차: 보호 로직 및 소프트스타트, 통신 로깅 정비
  - 4주차: 하드웨어 디버깅, ZVS 검증, 파라미터 튜닝 및 문서화
